실거래 진단 — 시도 카드를 클릭하면 그 시도의 모든 단지를 점검합니다. 같은 시군구 단지들은 실거래 API를 1회만 호출해 공유하고, 결과는 서버에 캐시되므로 재진단 시 API를 다시 부르지 않습니다. 문제 단지는 ❌로 표시되며 [복사] 버튼으로 내용을 복사해 Claude에게 붙여넣으면 수정받을 수 있습니다.
건축물대장 — 시도 클릭 시 용적률·건폐율 등 빠진 단지를 찾아 자동보완(건축물대장 API 재조회)하거나 직접 입력해 저장합니다.
🔍 시도별 실거래 진단
클릭 한 번 = 해당 시도 전체 점검. ✅정상(거래 매칭됨) ❌매칭의심(이름 비슷한 거래가 있는데 매칭 실패) ⚠️API오류 ➖거래없음(조용한 단지일 수 있음). 정상 판정 단지는 30일간 자동 스킵.
