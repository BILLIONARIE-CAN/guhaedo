### PNU 코드 계산법
PNU = 법정동코드(10자리) + 토지구분(1: 토지, 2: 임야) + 본번(4자리, 앞에0패딩) + 부번(4자리, 앞에0패딩)

카카오 주소검색 API 응답 → `address.b_code` (10자리 법정동코드)
지번 본번/부번 → `address.main_address_no`, `address.sub_address_no`

```javascript
// PNU 조합 예시
function buildPNU(bCode, mainNo, subNo, isForest=false) {
  const landDiv = isForest ? '2' : '1';
  const main = String(mainNo||0).padStart(4,'0');
  const sub  = String(subNo||0).padStart(4,'0');
  return bCode + landDiv + main + sub; // 19자리
}
```

### 건축HUB API 파라미터 추출
```javascript
// 법정동코드(10자리) → sigunguCd(5자리) + bjdongCd(5자리)
const sigunguCd = bCode.slice(0,5);
const bjdongCd  = bCode.slice(5,10);
// bun/ji = 본번/부번
```
