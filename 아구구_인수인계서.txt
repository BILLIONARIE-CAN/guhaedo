### 4. 🔴 신축 단지 "거래내역없음" = 분양권 지연으로 함수 시간초과 (수정 완료, 2차 푸시 필요)
- **증상**: 신축(준공 ±1년) 단지 차트가 "거래내역없음". 구축은 정상. (캐시 안 된 달이 섞인 요청에서 발생)
- **원인**: 신축은 분양권(pre) 호출이 켜지는데(wantPre=true), 분양권 API가 무응답으로 매달림 → `/api/trade` 함수가 Vercel 제한시간(약 10초) 초과 → 504/빈 응답 → 프론트 `if(!d)break` → "거래내역없음". (구축은 wantPre=false라 분양권 호출 안 해서 멀쩡했음)
- ⚠️ v9에서 넣었던 diag.js 분양권 15초 재시도도 같은 함정(diag도 Vercel 함수 → 백필이 diag 504 받으면 다시 멈춤) → **fail-fast로 철회**
- **수정**:
  - `api/trade.js`: 분양권 타임아웃 **3초 fail-fast**(매매/전월세 5초), 배치 동시처리 6→12(미보유 월 1웨이브 처리) → 함수 총시간 < 10초 보장
  - `api/diag.js`: 분양권 재시도 제거 → **4초 fail-fast**, 매매/전월세 7초(캐시조회 2.5초 + 7초 < 10초)
- 참고: 신축의 '매매'는 대부분 분양권 거래라, 분양권 API가 죽어 있으면 timeout을 고쳐도 매매 점은 비어 보일 수 있음(전세/월세는 표시됨). 분양권 점은 data.go.kr API 정상화가 별도로 필요

### 5. 🔴 일부 단지 "거래내역없음" = 오염된 빈 캐시 (캐시 버전컷 갱신)
